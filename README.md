# C64 Circuits
A circuit building game in C64 BASIC

## How to play

A hidden wire runs from one pad to another across the board. The numbers along the top and left show how many wire segments are in each column and row. Work out where the wire goes and rebuild it.

The wire never crosses or touches itself, and every segment connects to the next. Connect pad to pad with all counts right to advance to a bigger board.

## Controls

| Key | Action |
|---|---|
| Cursor keys or W/A/S/D | Move |
| SPACE | Cycle cell: empty, straight, corner, or X (no wire) |
| X | Mark cell as no wire |
| . | Clear cell |
| RETURN | Check your circuit |
| I | Instructions |
| Q | Quit |
