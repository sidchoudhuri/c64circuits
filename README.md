A circuit building puzzle in pure C64 BASIC V2, with SID music and a self-playing demo. By m0nde.

https://m0nde.itch.io

## The game

A hidden wire runs from one pad to another across a circuit board. You can't see it. All you get is a number at the head of every column and the start of every row: how many wire segments sit in that line. Work out where the wire goes and rebuild it with straight and corner pieces.

The wire never crosses or touches itself, and every segment connects to the next. Row and column counts have to match, and the pieces you place have to form one connected wire from pad to pad.

**Any valid circuit wins.** The game doesn't compare your board with the hidden one. It walks your wire from the entry pad, step by step, and wins when it reaches the exit pad, every piece you placed is on that one path, and all the counts are right. If two different circuits fit the clues, both are accepted.

### Boards that chain together

Solving a board doesn't throw you at a new screen. The solved board stays, turns light blue with grey clues, and the next board of the same size starts where the last one ended. Boards chain in a snake (left to right, down, then right to left) until the screen is full. Then the size steps up.

| Stage | Board | Boards in the chain |
|---|---|---|
| 1 | 5x5 | 15 |
| 2 | 6x6 | 8 |
| 3 | 7x7 | 8 |
| 4 | 9x9 | 3 |
| 5 | 12x20 | 1 |
| 6 | 15x28 | 1 |
| 7 | 17x36 | 1 |

That is 37 levels, shown as stage-board: `LVL 1-1` to `LVL 1-15`, then `LVL 2-1` and so on. Clear the last one and the grid comes online: `MAIN GRID: ONLINE`, `CORE FREQUENCY: 50HZ STABLE`, `GRID SYNCHRONIZED.` Press a key to start again, or Q for the menu.

## What is on the disk

`c64circuits.d64` has everything the game needs. The programs depend on each other, so keep them together.

| File | What it is |
|---|---|
| `C64CIRCUITS` | The loader and menu. Run this one. |
| `CIRCUITS` | The game |
| `CIRCUITSDEMO` | The self-playing demo |
| `CIRCUITSMUSIC` | The SID music player and tune, loaded at $9000 |

The directory also has a pad, a winding wire and a second pad drawn in PETSCII between the loader and the game.

To start it:

```
LOAD"*",8
RUN
```

## The menu

| Key | Action |
|---|---|
| P | Play |
| D | Watch the demo |
| I | How to play |
| C | Credits |
| S | SID setup |
| Q | Quit (asks Y/N) |

The title screen draws a wire growing from pad to pad across the same dotted board the game uses. It picks a new route each time.

## Controls

| Key | Action |
|---|---|
| Cursor keys or W/A/S/D | Move |
| SPACE | Cycle the cell: empty, straight, corner, or X (no wire) |
| X | Mark the cell as no wire |
| . | Clear the cell |
| RETURN | Check your circuit |
| R | Reveal the hidden circuit |
| I | Instructions |
| M / E | Music / sound effects volume (two SIDs) |
| V | Volume (one SID) |
| Q | Back to the menu (asks Y/N) |

The check tells you what is wrong: `ROW/COL COUNTS OFF` with how many lines are off, or `COUNTS MATCH, NOT CONNECTED`.

## Features

- **Pure BASIC V2.** The game, demo and menu are all BASIC. The only machine code is the small music player.
- **Any valid solution wins.** A connectivity check instead of a comparison with the hidden path.
- **Backtracking path generator.** Each board starts exactly where the last one ended, and the generator backs up and tries another route instead of starting over.
- **Compact header.** Two rows at the top: `C64 CIRCUITS     LVL 1-10   GRID 5X5`, then a hint on the left and a short status (`PAD TO PAD`, `COUNTS OFF: 2`, `NOT CONNECTED`, `CIRCUIT DONE!`) on the right. The hint changes with what is under the cursor and rotates through the keys while you think. A blank row separates the header from the boards. The demo shows `V:VOLUME Q:QUIT TO MENU` and `DEMO: <status>` instead.
- **Big boards.** Clues of 10 or more use two digits, with the tens digit above (columns) or to the left (rows). The biggest board is 17x36.
- **SID music.** "Pad to Pad", a simple electronic tune in A minor, with the noise channel used for soldering sounds: sometimes a long arpeggio, sometimes a short one.
- **Two SIDs.** The loader detects a second SID. With two, the music plays on the first and the sound effects on the second, with separate music and effects volume (M and E). With one, V sets both. S in the menu lets you override detection.
- **PAL and NTSC.** The music player keeps the same tempo on both.
- **Self-playing trailer (the demo).** Plays stage 1, all fifteen 5x5 boards, on its own and loops until you press Q: the same fifteen boards every time, solved by a cursor that walks the wire and places each piece with the game's sounds. A fine-scrolling text runs along the top row with the story, the music and the itch.io link. V, or M and E with two SIDs, change the volume. Q returns to the menu.
- **Colour.** Green board, yellow clues, cyan pads, light blue solved boards. The instructions screen colours keywords so they stand out.
- **Sound effects.** Click, tick, buzz and a rising fanfare, all on the SID.
